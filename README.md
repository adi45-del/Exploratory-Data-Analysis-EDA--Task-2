# Exploratory-Data-Analysis-EDA--Task-2
AI/ML Internship Task 2 – Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, Seaborn, and Plotly.
Tasks Performed:-
Explored the dataset using Pandas
Generated summary statistics (mean, median, standard deviation)
Created histograms and boxplots for numerical features
Used pairplot and correlation heatmap to analyze feature relationships
Identified important patterns and trends from visualizations

Key Inferences:-
Most passengers were between 20–40 years old
Female passengers had higher survival rates
Higher-class passengers had better survival chances
Fare column contained outliers

Tools Used:-

Python, Pandas, Matplotlib, Seaborn, Plotly
